## Raycast Extensions are on by default

- **Raycast Extensions now start switched on** on a fresh install, or on any Mac where the switch was never touched. You can install extensions from the Raycast Store straight away. Turning them on doesn't install or download anything by itself.
- **Your choice to switch them off is kept.** If you turned Raycast Extensions off before, they stay off. Turning them back on still asks you to confirm that extensions are third-party code.

## Fixes

- **A Raycast keep-awake task now stops when you stop it.** A Coffee-style "keep awake" row could stay in the launcher's background tasks forever. That happened when Settings Sync copied it back from another Mac. Keep-awake rows now stay on the Mac that started them.
- **Each Mac now syncs only the background tasks it started.** A Mac no longer copies a row it received from another Mac back into your settings file. A finished task can't come back that way.
- **Less sync traffic.** A running keep-awake timer no longer rewrites your settings file every second.

If a stuck row from an earlier version is still showing, it clears the next time this Mac writes your settings file and Spotter relaunches.

Updating from 1.7.37 or later installs normally through Check for Updates. If you are still on 1.7.36 or earlier, install this version from the DMG once and grant Accessibility, Input Monitoring, Screen Recording and Full Disk Access again, as described in the 1.7.37 notes.
