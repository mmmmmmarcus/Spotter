# Spotter 1.6.29

## Highlights

- Quick AI Chat now uses a Siri-inspired Liquid Glass surface with two-stage expansion, a draggable header, a clearer composer and live response progress.
- Jev now routes unpinned prompts to your configured Everyday, Professional or Deep Reasoning model.

## AI

- Run chats through a locally installed Claude Code or Codex CLI.
- Attach text, source, PDF and image files; Spotter extracts readable text locally before sending it to the selected model.
- Render display math in AI responses.
- Open AI commands in Quick AI Chat by default and show their source text as compact command bubbles.
- Use configured MCP and Cua servers without a separate tools toggle.

## Productivity

- Search and run Apple Shortcuts directly from Spotter.
- Search open windows and the frontmost app's menus.
- Use dynamic values in Snippets and Quicklinks, plus richer Quicklink actions.
- Import Snippets and Quicklinks from an encrypted Raycast export.
- Join the next online meeting or copy its link from Calendar commands.

## Clipboard and Settings

- Quick Clipboard now starts with All items, loads more as you browse, switches categories with Tab and presents images in a three-column grid with four-direction keyboard navigation.
- Search text found locally inside clipboard images and PDFs, and see color values as swatches.
- Settings has a simpler layout with clearer permissions, streamlined AI model choices and Weather controls in General.

Update from **Spotter Settings → About → Check for Updates**, or download the new build from GitHub Releases.
