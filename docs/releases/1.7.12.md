## Improvements

- Quick Clipboard History now displays text, images, and files in a compact three-column square grid with up to four visible rows. Text wraps inside each tile, images fill their square, and older entries remain available by scrolling.
- Navigate every Quick Clipboard category with all four arrow keys, and use Tab to switch categories. The fixed four-row layout replaces the former visible-item count setting; existing clipboard history is preserved.
- AI Command messages now show the command name and symbol together in a capsule at the top of the message bubble.
- Check for Updates uses one command that changes with the current state. Available updates show the current and new version, and can be installed without moving keyboard selection. Release notes appear directly without a repeated heading.
- Screenshot selection prepares screen snapshots directly and concurrently across displays to reduce startup waiting while preserving frozen-screen selection.

Update through Check for Updates in Spotter, or download the DMG and drag Spotter to Applications.
