## What's new

- View Release Notes directly in Software Update and Settings after checking for updates, including when you already have the latest version.
- Quick AI Chat now has a native window shadow to help separate its compact input and expanded conversation from the desktop.

## Fixes

- Ordinary AI questions no longer fail when Cua Driver is missing or an MCP server cannot connect. Available servers remain usable; when no tools are available, chat continues with a streamed response using your selected model.
- Failed MCP discovery no longer exposes a partially loaded tool list. Cancelling a request, revoking access, or encountering an actual tool execution error still stops the affected operation.

Every release now includes written release notes, checked before publication and displayed in the app.

Update through Check for Updates in Spotter, or download the DMG and drag Spotter to Applications.
