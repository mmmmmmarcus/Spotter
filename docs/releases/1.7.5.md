# Spotter 1.7.5

## Screenshot fixes
- Screenshot selection now freezes the display before dragging, preserving Notification Center and other temporary UI even when a click dismisses them.
- Region screenshots, text recognition, full-screen capture and color picking use the same frozen image, with Retina and 1x output supported.
- Cancelling a capture no longer allows its pending work to report an error into a newer capture.

## Stability
- Fixed a recursive settings update that could crash Spotter when restoring or changing the Quick Clipboard History item count.
