## Improvements

- Fix Spelling is now Fix Selected Text: Hyper+F corrects spelling for one or two words, and also fixes grammar and punctuation for longer selections while preserving meaning and tone.
- Compatible editors show `{Fixing}` directly in the selection, then replace it with the finished correction. No chat window or status Toast is shown.
- Existing command shortcuts, custom prompts, model choices and thinking-effort settings are preserved. The original shipped prompt upgrades automatically.

## Fixes

- Improve selected-text replacement in Grok Bot, Chrome text fields and rich-text editors, and Figma canvas text. Native selection prevents corrections from being appended after the placeholder in Figma.
- Keep newer typing intact and prevent corrections from being pasted into a different app. If a correction is interrupted while another app is active, restore the unchanged original selection when returning to the source app.
