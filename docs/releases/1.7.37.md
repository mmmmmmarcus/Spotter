## A new signing certificate

- Spotter is now signed with its own Apple developer certificate instead of a company one. The app itself is unchanged, but macOS identifies an app by who signed it, so this build looks like a different app to the system.
- **This update has to be installed by hand.** Check for Updates will not offer it, and will keep refusing it: the updater deliberately rejects any build whose signature does not match the copy you are running, which is what protects you from a substituted update. Download the DMG and drag Spotter to Applications, replacing the existing copy.
- Once it is replaced, Spotter has to ask again for the permissions it already had — Accessibility, Input Monitoring, Screen Recording and Full Disk Access. macOS ties those grants to the signature, so they do not carry over. Until Accessibility is granted again, global hotkeys and pasting will not work.
- Your settings, clipboard history and Notes are untouched, and later updates install normally through Check for Updates again.

Download the DMG and drag Spotter to Applications. Check for Updates cannot deliver this one.
