## Permissions

Settings → Permissions has been rebuilt. It previously listed four permissions and could not reliably tell you whether any of them was actually granted. It now reports the live state of every permission Spotter uses, and keeps reporting it while the pane is open — so revoking something in System Settings stops it reading as granted here.

- **Screen Recording is detected correctly, and screenshots no longer break until you relaunch.** macOS answers the "do I have Screen Recording?" question once per launch and then repeats that first answer for as long as the app runs. If you granted Screen Recording while Spotter was already running, Spotter went on believing it had been refused: the Permissions row stayed stuck, and — the real damage — every screenshot command silently refused to capture anything until the next launch. Spotter now takes a second, live reading alongside that cached one, so a grant takes effect immediately in both places.

- **App Automation now has real per-app rows.** Spotter drives Finder, System Events, Music, Terminal and iTerm2 through Apple Events, and macOS grants each one separately. The pane used to show a single row with no state at all. It now lists every one of those apps that you have installed, each with its own state: Granted, Denied with a button to the right pane, Not yet asked, or Not running — because macOS genuinely reports no stored answer for an app that isn't open, and Spotter sends a closed app nothing either.

- **A missing Accessibility grant is now visible where it bites.** The Hyper Key needs Accessibility to work at all. If that grant is missing or has been revoked, Settings → General now says so in the Hyper Key section instead of leaving you with a key that does nothing for no stated reason.

All of this reads the system's own answers without ever raising a permission prompt, and the pane only checks while you are looking at it.

## Fixes

- Six alerts from system commands — the Bluetooth, Wi-Fi and Do Not Disturb toggles — introduced themselves as "Tinycast" rather than Spotter.
- When toggling Bluetooth fails because macOS wants a permission Spotter doesn't ask for, the alert now offers to open the right Privacy pane instead of just reporting the failure.
- A failure to start the double-tap key listener was previously recorded nowhere. It now appears in Settings → Diagnostics, like the rest of the hotkey subsystem.

## iPhone and iPad Notes

The companion Notes app (not distributed through this release) also changed:

- **Swipe left or right to move between Notes**, matching ⌘] and ⌘[ on the Mac. Scrolling, the swipe-down-to-dismiss keyboard gesture and tapping a checklist box all behave as before.
- **The keyboard toolbar is now monochrome.** Its buttons previously picked up the open Note's accent colour; they now use one consistent weight and size, in the system label colour, in both light and dark mode.

Updating from 1.7.37 or later installs normally through Check for Updates. If you are still on 1.7.36 or earlier, install this version from the DMG once and grant Accessibility, Input Monitoring, Screen Recording and Full Disk Access again, as described in the 1.7.37 notes.
