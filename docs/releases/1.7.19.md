## Improvements

- Quick Clipboard History now shows four columns and up to sixteen items at once, keeping the same tile size and adapting arrow-key navigation to the wider grid.
- Quick Clipboard History stays vertically scrollable without sideways drift from mouse or trackpad gestures.
- Try With adds Translate, Search Clipboard, and Search SF Symbols, carrying over the current query. The ChatGPT web shortcut has been removed from this group.
- Palette search places menu-bar commands in a separate Menu Bar group while preserving keyboard navigation and activation order.
- Settings displays each installed Raycast extension’s artwork. Other sidebar icons use monochrome tiles consistent with Clipboard History.
- The `kill <app name>` shortcut now finds menu-bar apps such as VibeRemote and ignores case and whitespace differences in application names.

Update through Check for Updates in Spotter, or download the DMG and drag Spotter to Applications.
