## AI model selection

- Jev automatic model selection is removed. Chat now uses the model and thinking effort you choose in Settings ▸ AI Chat ▸ Chat, and changing it applies to new conversations.
- Each AI command either uses its own model and effort or follows the chat model (shown as "Chat Model").
- A new Web Search switch in the same Chat section controls web search for every chat turn. It is off by default, since each search adds a per-request charge; Fix Text never searches.
- Your existing choices carry over: the previous Everyday model becomes the chat model, commands pinned to a category use that category's model and effort, and older backup and sync files migrate the same way. Existing conversations stay readable.

## Clipboard

- Copying an image file Spotter cannot read, such as one in a privacy-protected folder or arriving from another device, now keeps an image preview in clipboard history instead of showing only a file icon. The preview is stored by Spotter, so it no longer depends on Full Disk Access and survives app updates. Pasting still puts the original file back. Entries captured before this version keep their file icon.
