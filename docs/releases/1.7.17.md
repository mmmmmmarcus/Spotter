## More Reliable Updates

- Update checks now read a static feed hosted on GitHub Pages instead of the GitHub REST API, avoiding anonymous API rate limits shared by other apps and users on your network. Installation packages remain on GitHub Releases.
- Repeated checks are throttled, and server-requested retry times survive restarting Spotter. Network errors, server errors and invalid update information now have distinct messages, with a direct download link when a check fails.
- The website reads the same published version feed. Each release refreshes and verifies that feed after its installation packages are available.

Existing installations need to install this version once before using the new update source. If Check for Updates is currently blocked by GitHub API limits, download the DMG from this release, quit Spotter, and replace the app in Applications without deleting it first.

Updates still require your confirmation and verify the downloaded app's signing identity before installation.
