# Spotter 1.7.1

## Local AI CLIs

- Set a custom Codex CLI or Claude CLI executable path using **Settings → AI Chat → Local AI CLIs → Enter Path…**.
- Save an empty path to restore automatic detection. Custom paths stay on the current Mac and are not included in settings sync or backups.
- Show validation errors for missing, non-executable or unusable CLI paths, and prevent an older detection result from overriding a newer choice.
- Include the selected executable's directory when launching the CLI, improving compatibility with npm/nvm installations whose dependencies were unavailable when Spotter started outside a terminal.

Update through **Settings → About → Check for Updates**, or download Spotter from GitHub Releases.
