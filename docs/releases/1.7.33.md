## AI commands and Fix Text

- AI commands can now use the Everyday, Professional or Deep Reasoning preset, inheriting its model and thinking effort. Existing conversations retain their selected configuration.
- New installations default to Codex CLI GPT-6-Luna with Low, Medium and Extra High effort for the three presets. Existing model choices are preserved.
- New or reset Fix Text commands default to Gemini 3.5 Flash Lite with Minimal effort through OpenRouter. Existing custom command settings remain unchanged; select this model in the command editor to switch.
- Fix Text now cycles through `{Fixing.}`, `{Fixing..}` and `{Fixing...}` while waiting, with guarded completion and cancellation.
- Improved replacement when an editor resets the caret to the start of the placeholder, including the reported ChatGPT case. Errors appear in a Toast, and diagnostics help identify failed replacements without recording text contents.
