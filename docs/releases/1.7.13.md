## Improvements

- Search the current application's menu commands directly in the main Palette, with application and menu-path labels. Switch Windows retains its dedicated search screen.
- Menu searches stop when the Palette closes and limit traversal time, depth and visited items. Activation rechecks the indexed menu path and refuses changed or disabled items.

The separate Search Menu Bar Items command and shortcut registration have been removed; existing saved shortcut values remain untouched. Menu search requires Accessibility access. Without access, ordinary launcher search remains available.

Update through Check for Updates in Spotter, or download the DMG and drag Spotter to Applications.
