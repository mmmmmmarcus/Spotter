# Spotter 1.7.3

## Quick AI Chat
- All AI conversations now open in Quick AI Chat, with a history sidebar grouped by Today, Yesterday, This week and Earlier. Drafts and attachments are preserved when switching sessions.
- Opening or closing history keeps the conversation width steady. The compact history button sits outside the composer, and header controls have native Liquid Glass styling.
- Sent messages animate from the composer into the conversation. Dragging Quick AI Chat or the palette now keeps a closed-hand cursor until release.
- Quick AI Chat and floating Notes now explicitly participate in Mission Control and window cycling.
- Added richer Markdown rendering, including hyperlinks, nested lists, tables, task lists, syntax-highlighted code with copy controls, formulas and Mermaid diagrams. Remote images appear as links and HTML is displayed as text.

## AI settings and attachments
- Reorganized provider, model, command and MCP settings. AI commands have editable SF Symbols, and configured MCP servers can be managed directly in the list.
- Added specific Codex CLI model choices for routing. Jev decides whether each turn needs web search.
- Improved file attachments, including SVG text, images and PDFs across supported providers.

## Raycast extensions
- Install extensions from the palette with Raycast extension store. Each installed extension has its own settings page in the Raycast Extension group.
- Improved command icons, argument entry, actions and extension settings integration.

## Translation and everyday tools
- Translation panels show muted source text while waiting, then transition to the result. Added copy and bilingual comparison controls with optional AI word alignment and linked word highlighting.
- Quick Clipboard History can show 5–12 items by default, with a matching panel height.
- Updated World Clock rows with clearer date, offset and day/night information and animated time changes.
- Improved screenshot selection contrast in both appearances and fixed a crash when opening Settings.
