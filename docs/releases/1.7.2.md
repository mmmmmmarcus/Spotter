# Spotter 1.7.2

## A leaner Spotter
- Removed the built-in Mole, Change Case, Caffeinate and Image Modification plugins, including their settings, commands and shortcuts. Install alternatives from Settings → Raycast Extensions as needed.
- Removed the launcher’s Uninstall with Mole action. Existing local plugin preferences are left untouched; older backups remain readable.

## Raycast extensions
- Fixed a crash when opening extension command screens, found while testing Slack.
- Installation now shows a completion message and expands the installed extension’s commands. Pending browser sign-in has a clear status message.

## Local AI chat
- Claude and Codex now run in Spotter’s dedicated AI Chat workspace instead of the user’s home directory.
- Codex replies use structured output, keeping startup logs and prompt echoes out of the conversation. Model-cache and startup failures show concise diagnostics.
