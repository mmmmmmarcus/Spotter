## Fix Spelling feedback and recovery

- Fix Spelling now immediately shows `{Fixing}` in the captured selection, then replaces it with the complete correction. Failed, canceled or superseded requests restore the original while the document is unchanged; newer user edits are preserved. Quitting Spotter also cancels pending spelling work and attempts this guarded restoration.
- Replacement rechecks the original editor, document and selection. Unsupported editors are refused before a model request. Spotter Notes preserves the selection's formatting, and Undo returns to the original text without exposing the temporary placeholder.
- The default spelling shortcut changes from Hyper+W to Hyper+F. Existing default bindings migrate only when the destination is free; custom shortcuts, deliberate unbinding and conflicts are preserved.
- Fixed startup ordering so shortcut migration runs after the initial settings-sync read, preventing an older synced snapshot from immediately restoring the retired default.

Update through Check for Updates in Spotter, or download the DMG and drag Spotter to Applications.
