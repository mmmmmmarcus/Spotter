## Notes storage improvements

- Notes now use stable UUID-based Markdown filenames. Editing a title updates the same file instead of renaming it, reducing sync churn and unwanted Trash entries.
- Existing title-named files migrate automatically while preserving their note IDs, content, timestamps, colors, and additional header fields.
- Byte-identical duplicate files are cleaned up without going to the Trash. Explicitly deleted notes still go to the Trash, and a failed Trash operation no longer falls back to permanent deletion.
- Empty title drafts no longer create sync files that are discarded when the Notes window closes.
- Folder sync rechecks files before writing or removing them, preserves newly occupied or unavailable paths, and recovers interrupted filename migrations.

## Shared Notes folders

Update every Mac sharing the same Notes folder to this version. Older versions still rename files after their titles and can reintroduce file churn. Notes remain ordinary Markdown files; their titles stay in the first heading. Existing local notes and backups retain their IDs and format.

Update through Check for Updates in Spotter, or download the DMG and drag Spotter to Applications.
