## Settings Sync

Four settings that previously stayed on one Mac now travel in your settings file, through both Settings Sync and manual Export & Import:

- **Clipboard text search** — whether Spotter reads text out of copied images and PDFs. Turning it on through a sync starts indexing straight away, just like flipping the switch in Settings → Clipboard.
- **Raycast Extensions: Show Commands in Launcher** — applied immediately on the receiving Mac.
- **Raycast Extensions: Package Manager** — your chosen package manager for installing extensions.
- **Raycast extension icons** — the symbol and tint you picked for each extension. An extension that isn't installed on the receiving Mac simply keeps the choice for when it is.

Removing an icon override on one Mac now removes it on your other synced Macs too, the same way favorites and other synced lists behave.

Some Raycast settings deliberately stay on each Mac: the Enable Raycast Extensions switch (it is your consent to run third-party code on that Mac), custom search paths, the installed extensions themselves, their stored data and sign-in tokens.

A file written by an older version of Spotter carries none of these fields, and leaves this Mac's current choices untouched.

Updating from 1.7.37 or later installs normally through Check for Updates. If you are still on 1.7.36 or earlier, install this version from the DMG once and grant Accessibility, Input Monitoring, Screen Recording and Full Disk Access again, as described in the 1.7.37 notes.
