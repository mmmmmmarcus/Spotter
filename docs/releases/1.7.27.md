## Fix Spelling in place

- Fix Spelling now replaces selected text directly without opening AI Chat or creating a conversation. Its default shortcut remains Hyper+W, and it uses your configured command model, including Codex CLI.
- Spotter checks that the original editable selection is still focused before replacing it. Changed selections, failed or canceled requests, and incomplete responses leave your text untouched. Apps that cannot expose a verifiable editable selection show a brief message instead.
- Pronunciation and other AI commands continue to open Quick AI Chat.

## Raycast extension compatibility

- Improved OAuth sign-in for custom authorization URLs, state overrides and client metadata redirects. Missing, stale or duplicate callback states are rejected while preserving Spotter's existing login and token storage.
- Updated the compatibility API definitions to Raycast 2.8.2, including the Quicklink icon. Newly introduced Raycast AI methods report a clear unsupported-feature error instead of failing as missing functions.
