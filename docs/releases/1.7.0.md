# Spotter 1.7.0

## Raycast Extensions

- Install and run Raycast extensions in Spotter using the Tinycast-derived compatibility runtime.
- Search Raycast Store, install from GitHub source, import built extension folders or import extensions already installed in Raycast.
- Use native lists, grids, forms and detail views, with action menus, extension preferences and configurable command shortcuts.
- Support compatible menu-bar commands, background refresh and OAuth sign-in flows.
- Check for extension updates, uninstall extensions and clean unused extension data from Settings.

Enable the feature in **Settings → Raycast Extensions**, then search installed commands in the main Palette. Extensions run third-party code with access to files, processes and their own network services, so enable and install extensions you trust. Store packages run without Node.js; GitHub source builds require a local Node.js toolchain. Compatibility follows Tinycast's supported APIs; Raycast's proprietary AI, BrowserExtension and WindowManagement APIs remain unavailable.

## Quick AI Chat

- Animate the floating window when it appears and disappears.
- Refine the expansion curve for a quicker, smoother transition while retaining two-stage expansion.
- Show response progress as animated text without a leading symbol.

## Translate

- Show selected-text translations in a compact floating Liquid Glass bubble near the pointer, displaying the translated result without repeating the original text.

Update from **Settings → About → Check for Updates**, or download Spotter from GitHub Releases.
