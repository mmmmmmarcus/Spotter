## Fixes

- Notes now replace an empty destination list marker when pasting a copied list block, preventing duplicated bullet, numbered and checkbox prefixes. Copied task state and nesting are preserved, and the paste remains undoable in one step.
- Plain text, occupied list items, partial selections and fenced code keep their normal paste behavior.

Update through Check for Updates in Spotter, or download the DMG and drag Spotter to Applications.
