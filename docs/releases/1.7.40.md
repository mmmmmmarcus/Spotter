## New

- **Act on a translation without reaching for the mouse.** The bubble that appears over your selected text now carries a Replace Selection button beside Copy, and three keys while it is on screen: **↵** copies the translation and closes the bubble, **⌘↵** writes it straight over the text you selected, and **↓** opens the original-and-translation comparison (**↑** closes it again).

  Replace Selection appears only when there is a selection to write back into, so it is absent from the Translate page and from a bubble that failed. Before it writes anything it rechecks that the same app, the same text field and the same selection are still there, and if they are not it leaves your text completely untouched and tells you why. The replacement is a single edit, so one ⌘Z undoes it.

  While a translation is on screen the bubble holds those keys, so a Return typed into the app behind it will close the bubble instead. Escape, or a click anywhere outside, hands every key straight back.

## Fixes

- **Quick Clipboard History image thumbnails, properly this time.** 1.7.38 described this as fixed and it was not — the real cause ran deeper. Thumbnails were decoded successfully and then fetched back out of a cache that could be emptied in between, and the empty answer was recorded as "this image cannot be read" for as long as the menu stayed open. Scrolling or switching category never asked for it again, so one unlucky moment turned the whole grid into placeholders until the menu was closed. Thumbnails are now handed back directly, so that gap no longer exists, and an image that genuinely cannot be read is reported rather than passed over in silence.

  As before, nothing in your history was affected: the images were saved correctly the whole time.

Updating from 1.7.37 or later installs normally through Check for Updates. If you are still on 1.7.36 or earlier, install this version from the DMG once and grant Accessibility, Input Monitoring, Screen Recording and Full Disk Access again, as described in the 1.7.37 notes.
