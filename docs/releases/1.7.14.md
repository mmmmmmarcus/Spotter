# Spotter 1.7.14

- Update installation now waits for Spotter to fully exit before replacing the app, then relaunches before cleaning up the retired bundle.
- Added image-preview failure diagnostics that distinguish missing files, permission failures and decoding errors without logging clipboard content or filenames. Exported Diagnostics also includes the latest updater handoff result.
- Screenshot selection keeps the desktop live instead of freezing it. A temporary mouse interception layer protects the underlying interface from selection clicks; pixels are captured when selection finishes. Screen Recording and Accessibility access are required.

The new installation sequence takes effect for updates performed by this version onward. Updating an older version to 1.7.14 still uses its existing updater; this release does not claim to restore already-lost macOS permissions automatically.
