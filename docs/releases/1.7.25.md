## New AI commands

- Fix Selected Text Spelling corrects spelling and typing errors while preserving wording, language and formatting. Its default shortcut is Hyper+W.
- Get Selected Text Pronunciation provides IPA, syllable stress and a readable pronunciation guide, with regional variants where useful. Its default shortcut is Hyper+P. Pronunciation is text-only.
- Both built-in commands open Quick AI Chat and support custom prompts, icons, models and shortcuts. Existing command customizations are preserved.

## Coffee background tasks

- Coffee keep-awake sessions now appear in Background Tasks when the Palette search is empty, with remaining time and progress for timed sessions.
- Select the task and use Actions → Cancel to stop its keep-awake process without stopping unrelated sessions.
- Active tracked sessions return after Spotter relaunches. Finished sessions complete automatically; disabling extensions or uninstalling the owner stops its tracked work.

## Shortcut reliability

- Hyper defaults respect the Include Shift preference and do not overwrite existing bindings or claim shortcuts already in use.
- Older settings snapshots no longer clear the new AI command defaults. New snapshots continue to sync deliberate shortcut changes and unbinding.

Start a new Coffee session after updating to enable tracking; sessions started before this version are not adopted. Coffee schedules remain managed by the extension.

Update through Check for Updates in Spotter, or download the DMG and drag Spotter to Applications.
